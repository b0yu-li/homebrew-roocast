# homebrew-roocast

Homebrew tap for [Roocast](https://github.com/b0yu-li/roocast) — open-source freeware ([MIT](https://github.com/b0yu-li/roocast/blob/main/LICENSE)).

```bash
brew tap b0yu-li/roocast
brew install --cask roocast
```

Upgrade:

```bash
brew upgrade --cask roocast
```

DMGs are notarized Developer ID builds hosted on Cloudflare R2 (see the cask `url`).
