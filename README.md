# homebrew-roocast

Homebrew tap for [Roocast](https://github.com/b0yu-li/roocast) (freeware native macOS launcher).

```bash
brew tap b0yu-li/roocast
brew install --cask roocast
```

Upgrade:

```bash
brew upgrade --cask roocast
```
